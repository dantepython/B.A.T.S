# B.A.T.S
B.A.T.S is short for Best Assistant To Stay: An powerful assistant in the process to become a mega-machine. Bats runs locally on the computer and with
the power of plugins, is able to fully automate and control fragments of the computer.

## Progress
Right now, he is able to control my Spotify and has a Voice Guard Security System. Recently, he has been integrated with the Roblox Studio plugin, which
makes him able to control and create in a RS place, helping to program and build the game graphicly. ~Note: He still has a pretty basic plugin for RS, so
don't expect magic happening.
